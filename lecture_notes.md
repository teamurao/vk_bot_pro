# Занятие: «Расширение возможностей VK // ДЗ»

## Цели занятия

- Научиться работать с клавиатурами и кнопками в VK-ботах.
- Научиться отправлять и принимать медиа (фото, документы), а также получать информацию о пользователе.
- Научиться интегрировать AI-модели (Hugging Face) для генерации ответов.

## 1) Клавиатуры и кнопки

### Что есть в VK

- **Custom keyboard**: обычная клавиатура под полем ввода, удобна для сценариев меню.
- **Inline keyboard**: кнопки прямо в сообщении, удобны для быстрых действий "здесь и сейчас".

### Практические рекомендации

- Держите кнопки короткими и понятными (`Help`, `User info`, `Ask AI`).
- Не перегружайте экран: 3-6 кнопок на сценарий обычно достаточно.
- Делайте кнопку "Back to menu" почти в каждом разделе.
- Для кнопок с разными действиями задавайте разные цвета (`primary`, `secondary`, `positive`, `negative`).

## 2) Медиа и user info

### Отправка медиа

- Фото: можно отправлять вложением (`photo{owner_id}_{media_id}`) после загрузки через API.
- Документы: аналогично через upload server для документов и последующую отправку attachment.

### Прием медиа от пользователя

- Проверяйте поле `attachments` в событии сообщения.
- Определяйте типы (`photo`, `doc`) и отвечайте пользователю с подтверждением.
- При необходимости сохраняйте `owner_id`, `id`, `access_key` для повторного использования.

### Получение информации о пользователе

- Метод `users.get` позволяет получить имя/фамилию и дополнительные поля (`city`, `sex`, `bdate` и т.д. при наличии).
- Используйте user info для персонализации ответа и промпта к LLM.

## 3) Интеграция AI-модели (Hugging Face)

### Базовая схема

1. Пользователь отправляет вопрос.
2. Бот формирует промпт (системная роль + вопрос + контекст).
3. Бот делает HTTP-запрос к Inference API Hugging Face.
4. Возвращает пользователю сгенерированный ответ.

### Важные моменты

- Храните токены в `.env`, не в коде.
- Добавляйте таймаут и обработку ошибок API.
- Ограничивайте длину ответа (например, `max_new_tokens`), чтобы избежать очень длинных сообщений.
- Предусматривайте fallback (если AI недоступен, бот отвечает шаблонно).

## 4) Мини-архитектура бота

- `bot.py`: основной цикл Long Poll и роутинг команд.
- `keyboards.py`: сборка custom/inline клавиатур.
- `ai_client.py`: клиент для Hugging Face.
- `config.py`: загрузка настроек из окружения.
